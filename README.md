to build:
-
1st: git clone https://www..github.com/layeraudioai/stemstudiosupreme
-
2nd: cd to your stemstudiosupreme folder or open terminal in that folder
-
3rd: npm install
-
4th: npm run build
-
5th: stemstudiosupreme/dir folder has the final built index.html and 
  assets/*.js and assets/*.css files all entirely client-side ready to double click index.html without server hosting and use in firefox
-
the end.
